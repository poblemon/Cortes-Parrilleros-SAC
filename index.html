💡 ¿Por qué se borran los datos al recargar en Vercel?

Vercel solo aloja la pantalla visual. Para que los pesajes y despachos queden guardados permanentemente en tu empresa y se sincronicen entre computadoras y celulares, se utiliza una base de datos gratuita de Google Cloud (Firestore).

También puedes dejarlo configurado de forma fija en la variable manualFirebaseConfig al inicio del código JavaScript.

Pasos para obtener tu base de datos gratuita (en 2 minutos):
  1. Entra a console.firebase.google.com con tu cuenta de Google.
  2. Crea un proyecto llamado Cortes Parrilleros.
  3. En el menú lateral ve a Firestore Database > Crear base de datos (en modo de prueba).
  4. En Autenticación (Authentication) activa el método Anónimo.
  5. Ve a la rueda de Configuración del Proyecto > Tus apps > Web </> y copia el objeto firebaseConfig aquí.
